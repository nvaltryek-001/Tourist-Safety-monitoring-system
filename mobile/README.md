# SafeTrail tourist app (Expo)

See the main [README](../README.md#-tourist-mobile-app) for setup. Quick start:

```bash
cp .env.example .env          # set EXPO_PUBLIC_API_URL to your backend
npm install
npx expo install --fix        # aligns native module versions with your Expo SDK
npx expo start                # scan the QR code with Expo Go
```
